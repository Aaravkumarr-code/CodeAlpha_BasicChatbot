# CodeAlpha_BasicChatbot
A simple rule-based chatbot built using Python as part of the CodeAlpha Python Programming Internship. This project demonstrates the fundamentals of Python programming through a console-based chatbot that responds to predefined user commands.

🚀 Features

- 👋 Responds to hello
- 😊 Answers how are you
- 🤖 Tells its name
- 📋 Shows available commands with help
- 👋 Exits the chat with bye

🛠️ Technologies Used

- Python 3

▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Run:
   python chatbot.py
4. Start chatting with the bot.

📌 Sample Commands

- hello
- how are you
- your name
- help
- bye

🎯 Objective

The objective of this project is to understand Python basics such as loops, conditional statements, user input, and string handling by developing a simple interactive chatbot.
